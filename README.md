# EZFlashcards

A simple flashcards app built with plain HTML, CSS and JavaScript.

## Features

- Create and delete decks
- Add, edit and delete cards
- Import trivia questions from [Open Trivia DB](https://opentdb.com/)
- Study mode with card flipping, shuffling and Got It / Missed counts
- Best score saved for each deck
- Everything is stored in browser's localStorage

## Running it

The app uses JavaScript modules, so it needs a local server rather than opening `index.html` directly. For example:

```bash
python -m http.server
```

Then open http://localhost:8000.
